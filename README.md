# Portofolio Dafa Adi Raharjo

React 18 + Vite + Framer Motion. Semua konten ada di `src/data.js`.

```bash
npm install
npm run dev      # development
npm run build    # produksi (hasil di folder dist)
```

- Foto kartu: `public/foto.jpg` (ganti dengan foto yang lebih tajam jika ada).
- CV untuk tombol "Unduh CV": `public/CV_DAFA_ADI_RAHARJO.pdf`.
